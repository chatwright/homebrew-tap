# Chatwright Homebrew tap

Cask manifests for [Chatwright](https://chatwright.dev), published
automatically by GoReleaser from [chatwright/cli](https://github.com/chatwright/cli)
releases.

```sh
brew install --cask chatwright/tap/chatwright
```

The canonical install for macOS/Linux remains:

```sh
curl -fsSL https://chatwright.dev/install.sh | sh
```
